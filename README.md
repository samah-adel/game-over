# 🎮 Game Over

Game Over is a responsive web application that allows users to browse free-to-play games by category and view detailed information about each game using the Free-to-Play Games Database API.

## 🚀 Features

* Browse games by category:

  * MMORPG
  * Shooter
  * Sailing
  * Permadeath
  * Superhero
  * Pixel
* View detailed information for each game
* Loading screen while fetching data
* Responsive design using Bootstrap
* Modern UI with hover effects
* Dynamic content using JavaScript ES6 Modules

## 🛠️ Technologies Used

* HTML5
* CSS3
* Bootstrap 5
* JavaScript (ES6 Modules)
* Fetch API
* Free-to-Play Games Database API
* Font Awesome
